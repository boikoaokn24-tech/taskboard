# Звіт до Лабораторної роботи №2

1. Яка адреса сторінки в браузері? З яких частин вона складається?
Адреса виглядає так: http://127.0.0.1:5500/index.html. Вона складається з протоколу (http://), IP-адреси локального хоста (127.0.0.1), номера порту сервера (:5500) та шляху до конкретного файлу (/index.html).

2. Скільки запитів зробив браузер при завантаженні сторінки і чому саме стільки?
Браузер зробив 2 запити: перший — за самим HTML-файлом (index.html), а другий — за зображенням (logo.jpg), оскільки тег <img> у коді вимагає завантаження окремого ресурсу.

3. Що відбулось, коли ти поставив неправильний шлях до зображення?
Зображення зникло з екрана, на його місці з'явився альтернативний текст `alt`, а у вкладці Network з'явився червоний запит із HTTP-статусом помилки 404 (Not Found).

4. Чому зміни, зроблені через DevTools, зникли після F5?
Зміни через DevTools вносяться динамічно в оперативну пам'ять браузера (DOM-дерево), а не у вихідний файл на диску. При натисканні F5 браузер заново завантажує оригінальний файл із сервера, тому тимчасові правки стираються.

5. Хто в цій схемі клієнт, а хто сервер?
Клієнтом є веббраузер (Chrome/Edge), який надсилає запити й відображає сторінку. Сервером є локальний вебсервер Live Server у VS Code, який обробляє запити й віддає файли сайту у відповідь.
